## 介绍

C 语言是一种广泛使用的通用编程语言

- 历史悠久, 社区支持强大
- 面向过程编程, 简洁高效
- 可移植性强, 灵活性高
- 编译型语言, 执行效率高

## 为什么需要先学习 C 语言?

由于 Rust 是一个新兴语言, 可以说是站在巨人的肩膀上设计而来, 但是它的内存管理比较特别, 
与以往学习过的编程语言都不一样, 而学习 C 语言可以让我们明白, 如何手工管理内存以及为什
么需要手动管理内存

总的来说: `学习 C 语言基础可以让我们在学习 Rust 的时候理解更加深刻`
