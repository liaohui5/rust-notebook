## 类型理解

- [字符串切片 &str](https://rustwiki.org/zh-CN/std/primitive.str.html) 是最原始的字符串类型
- [可增长字符串 String](https://rustwiki.org/zh-CN/std/index.html) 是一个标准库中的模块(包含结构体/接口等)

他们二者可以相互转换
