## 类型理解

他们二者可以相互转换, 因为本质都是用于描述"字符串"这个概念的

- [字符串切片 &str](https://rustwiki.org/zh-CN/std/primitive.str.html) 是最原始的字符串切片类型, 不可变引用, 固定大小(胖指针+长度)
- [可增长字符串 String](https://rustwiki.org/zh-CN/std/index.html) 是一个标准库模块中的结构体, 拥有所有权, 用其他编程语言的话说他是一个类一个引用类型

> 关键差异说明

1. String独有特点:
   - 所有修改操作(push、insert、remove、pop等)
   - 容量管理(capacity、reserve、shrink等)
   - 所有权转移(into_bytes、into_boxed_str等)
   - 原地修改(make_ascii_*、replace_range等)

2. 共有但行为不同:
   - `to_string()` / `to_owned()`: String克隆自身，&str创建新String
   - `as_str()`: String借用，&str返回自身
   - 所有修改方法在&str上不可用

### 创建

```rust
use std::any::type_name;

fn print_type<T: std::fmt::Debug>(var: &T) {
    println!("类型: {}, 值: {:?}", type_name::<T>(), var);
}

fn main() {
    // 1.直接创建 &str(字面量就是字符串切片)
    let str = "hello";
    print_type(&str); // &str

    // 2.直接创建 String
    let string = String::new();
    print_type(&string); // String

    // 3.直接创建可变 String
    let mut string = String::new();
    string.push_str("hello");
    print_type(&string); // String

    // 4.使用宏创建字符串
    let string = format!("{}-{}", 1, "2");
    print_type(&string); // String
}
```

### 查找搜索

这些方法, String 和 &str 都可以使用

```rust
fn main() {
    let str = "hello rust";

    //===  1.查找 子字符串 第一次出现 ===//
    // 1.1: , 返回一个 Option<usize> 类型的值
    let index = str.find("rust").unwrap();
    println!("index = {index}"); // 6

    // 1.2: 从右边开始查找子字符串第一次出现的位置, 返回一个 Option<usize> 类型的值
    let rindex = str.rfind("rust").unwrap();
    println!("rindex = {rindex}"); // 6

    //=== 2.查找所有子字符串 ===//
    // 2.1: 查找所有子字符串, 返回一个迭代器, 元素是 &str
    let str = "abcXXXabcYYYabc";
    let items = str.matches("abc").collect::<Vec<_>>();
    println!("{items:?}"); // ["abc", "abc", "abc"]

    // 2.2: 从右边开始查找所有子字符串, 返回一个迭代器, 元素是 &str
    let str = "abcXXXabcYYYabc";
    let items = str.rmatches("abc").collect::<Vec<_>>();
    println!("{items:?}"); // ["abc", "abc", "abc"]

    //=== 3.查找所有子字符串及开始位置 ===//
    // 3.1: 查找所有子字符串及开始位置
    // 返回一个迭代器, 元素是元组(index, sub_str)
    let items: Vec<_> = str.match_indices("abc").collect();
    println!("{items:?}"); // [(0, "abc"), (6, "abc"), (12, "abc")]

    // 3.2: 从右边开始查找所有子字符串及开始位置
    // 返回一个迭代器, 元素是元组(index, sub_str)
    let items: Vec<_> = str.rmatch_indices("abc").collect();
    println!("{items:?}"); // [(12, "abc"), (6, "abc"), (0, "abc")]
}
```

### 截取/修剪

这些方法 String 和 &str 都可以使用

```rust
fn main() {
    // 0.通过 切片语法截取
    // 返回截取的字符串, 但是如果越界会导致 panic
    let str = "hello world";
    let sub_str = &str[3..5];
    // let sub_str2 = &str[3..100]; // 会panic
    println!("1: {sub_str}"); // lo

    // 1.get 截取指定(切片)位置的字符
    // 返回一个 Option, 越界不会panic, 会返回 None
    let str = "hello world";
    let sub_str = str.get(4..=6).unwrap();
    println!("2: {str}"); // hello world
    println!("3: {sub_str}"); // o w

    // 2.split_at 在指定位置分割(左闭右开), 返回一个元组(前面部分, 后面部分)
    let items = str.split_at(5);
    println!("4:{items:?}"); // ("hello", " world")

    // 3.strip_prefix 移除前缀部分, 返回 Option 类型的值
    // 如果有前缀, 移除并返回 Some("剩余部分")
    // 如果没有前缀, 返回 None
    let str = "hello world";
    let sub_str = str.strip_prefix("hello").unwrap();
    let non_str = str.strip_prefix("abcd");
    println!("5: {sub_str:?}"); // world
    println!("6: {non_str:?}"); // None

    // 4.strip_suffix 移除后缀部分, 返回 Option 类型的值
    // 如果有后缀, 移除并返回 Some("剩余部分")
    // 如果没有后缀, 返回 None
    let str = "hello world";
    let sub_str = str.strip_suffix("world").unwrap();
    let non_str = str.strip_prefix("abcd");
    println!("6: {sub_str:?}"); // hello
    println!("7: {non_str:?}"); // None

    // 5.trim/trim_start/trim_end 删除开头结尾的空白字符(包括换行和空格)
    // 返回一个新的字符串, 不影响原来的字符串
    // trim: 开头结尾都删除
    // trim_start: 开头删除, 结尾不管
    // trim_end: 结尾移除, 开头不管
    let str = "\n hello world \n";
    let trim_str1 = str.trim();
    let trim_str2 = str.trim_start();
    let trim_str3 = str.trim_end();
    println!("8: {trim_str1}"); // "hello world"
    println!("9: {trim_str2}"); // "hello world \n"
    println!("10: {trim_str3}"); // "\n hello world"

    // 6.trim_matches/trim_start_matches/trim_end_matches
    // 删除开头结尾匹配到的字符, 注意闭包中的参数 c 是 char 类型
    // 可以传入一个闭包, 也可以传入一个 &str, 注意是按照每个字符去匹配是否要删除
    // 返回新的字符串, 不会影响原来的字符串
    let str = "abcba-hello rust-abcba";
    let trim_str1 = str.trim_matches(|c| 'a' == c || 'b' == c || 'c' == c);
    let trim_str2 = str.trim_start_matches("abc");
    let trim_str3 = str.trim_end_matches("abc");
    println!("11: {trim_str1}"); // "-hello world-"
    println!("12: {trim_str2}"); // "-hello world-abcba"
    println!("13: {trim_str3}"); // "-hello world-abcba"
}
```

### 分割字符串

::: code-group

```rust
fn main() {
    // split/rsplit/split_inclusive
    // 按照指定分隔符分割字符串
    // split: 从左往右分割, 不保留分隔符
    // rsplit: 从右往左分割, 不保留分隔符
    // split_inclusive: 从左往右分割, 保留分隔符
    // 返回一个迭代器, 最终得到的顺序看使用的是哪个方法
    let str = "foo@bar@baz";
    let iter = str.split("@");
    for item in iter {
        println!("{item}"); // foo bar baz
    }

    let iter2 = str.rsplit("@");
    for item in iter2 {
        println!("{item}"); // baz bar foo
    }

    let str = "foo@bar@baz";
    let iter3 = str.split_inclusive("@");
    for item in iter3 {
        println!("{item}"); // foo@ bar@ baz
    }

    // split_once/rsplit_once
    // 按照分隔符将字符串分成两半并返回
    // 返回一个 Option<(分隔符前的字符, 分隔符后的字符)>
    // 1.1: 如果没有找到分隔符则返回 None
    // 1.2: 如果分隔符后面没有内容, 则元组第二个元素为空字符串
    // 1.3: 如果风格符前面没有内容, 则元组第一个元素为空字符串
    let str = "@abc$def#";
    let non_str = str.split_once("&");
    println!("1.1 {non_str:?}"); // None

    let (before, after) = str.split_once("$").unwrap();
    println!("1.2 before: {before}, after: {after}"); // before: @abc, after= def#

    let (before, after) = str.split_once("@").unwrap();
    println!("1.2 before: {before}, after: {after}"); // before: "", after="abc$def#"

    let (before, after) = str.split_once("#").unwrap();
    println!("1.2 before: {before}, after: {after}"); // before: "@abc$def", after=""

    // split_at/split_at_mut
    // 按照索引将字符串切分为两份
    // split_at: 返回的是不可变引用
    // split_at_mut: 返回的是可变引用
    let str = "hello-world";
    let (before, after) = str.split_at(5);
    println!("2.1: before:{before}"); // hello
    println!("2.2: after:{after}"); // -world

    // 注意并须是可变 String 引用
    let str: &mut str = &mut String::from("hello-wrold");
    let (before_mut, after_mut) = str.split_at_mut(5);
    before_mut.make_ascii_uppercase();
    after_mut.make_ascii_uppercase();
    println!("2.3: before:{before_mut}"); // HELLO
    println!("2.4: after:{after_mut}"); // -WORLD

    // splitn/rsplitn
    // 按照指定分隔符(Char), 切分为 n 个子字符串, 返回一个迭代器
    // splitn: 从左至右遍历分割
    // rsplitn: 从右至左遍历分割
    let str = "foo bar baz hello world";
    let iter = str.splitn(3, ' ');
    for item in iter {
        println!("{item}"); // "foo" "bar" "hello world"
    }

    let iter2 = str.rsplitn(2, ' ');
    for item in iter2 {
        println!("{item}"); // "world" "foo bar baz hello"
    }

    // split_whitespace/rsplit_ascii_whitespace
    // 按照空白字符分割, 返回一个迭代器
    // split_whitespace: 按照所有UTF8中的空白字符分割
    // rsplit_ascii_whitespace: 仅按照 ASCII 表中的空白字符(也就是英文半角的Space按键输入结果)
    let text = "Hello\u{3000}World"; // \u{3000} 是中文全角空格(Unicode 空白字符)
    let unicode_parts: Vec<&str> = text.split_whitespace().collect();
    let ascii_parts: Vec<&str> = text.split_ascii_whitespace().collect();
    println!("split_whitespace: {:?}", unicode_parts); // ["Hello", "World"]
    println!("split_ascii_whitespace: {:?}", ascii_parts); // ["Hello\u{3000}World"]

    // lines
    // 按照换行(\n)符分割, 返回一个迭代器
    let str = "Hello\nWorld";
    let lines = str.lines().collect::<Vec<&str>>();
    println!("lines: {:?}", lines); // ["Hello", "World"]
}
```

:::

### 链接字符串

所有返回迭代器的函数, 都可以通过 `collect` 方法收集为 `Vec<&str>`, 而这个类型可以使用 `join` 方法

```rust
//  分割链接
fn main() {
    let str = "Hello\nWorld";
    // 其他返回迭代器的方法也可以这样使用
    let lines = str.lines().collect::<Vec<&str>>().join(",");
    println!("{lines}"); // Hello,World
}
```
