## std::net

`std::net` 是 Rust 标准库的**网络编程**模块(注意: 不是 std::io::net, 那是笔误), 提供了 TCP/UDP 通信所需的类型

### 介绍

`std::net` 中比较重要的类型:

| 类型                                                                       | 作用                                   |
| :------------------------------------------------------------------------- | :------------------------------------- |
| [TcpListener](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html)  | TCP 服务器端, 监听端口接收连接         |
| [TcpStream](https://rustwiki.org/zh-CN/std/net/struct.TcpStream.html)      | TCP 连接(客户端和服务器都能用)         |
| [UdpSocket](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html)      | UDP 套接字(无连接, 数据报)             |
| [IpAddr](https://rustwiki.org/zh-CN/std/net/enum.IpAddr.html)              | IP 地址(IPv4 或 IPv6)                  |
| [SocketAddr](https://rustwiki.org/zh-CN/std/net/enum.SocketAddr.html)      | 地址: "IP:端口" 的组合                 |

### IP 地址与端口

#### IP 地址解析

| 方法                                                                                           | 作用                             |
| :--------------------------------------------------------------------------------------------- | :------------------------------- |
| [IpAddr::is_ipv4](https://rustwiki.org/zh-CN/std/net/enum.IpAddr.html#method.is_ipv4)           | 是否是 IPv4 地址                 |
| [IpAddr::is_ipv6](https://rustwiki.org/zh-CN/std/net/enum.IpAddr.html#method.is_ipv6)           | 是否是 IPv6 地址                 |
| [IpAddr::is_loopback](https://rustwiki.org/zh-CN/std/net/enum.IpAddr.html#method.is_loopback)   | 是否是回环地址(127.0.0.1 / ::1)  |
| [IpAddr::is_private](https://rustwiki.org/zh-CN/std/net/enum.IpAddr.html#method.is_private)     | 是否是内网地址(192.168.x.x 等)   |

```rust
use std::net::{IpAddr, Ipv4Addr, Ipv6Addr};

fn main() {
    // 1. 字符串解析为 IP 地址
    let ip: IpAddr = "127.0.0.1".parse().expect("解析失败");
    println!("{ip}"); // 127.0.0.1

    // 2. 直接构造
    let v4 = Ipv4Addr::new(192, 168, 1, 100);
    println!("{v4}"); // 192.168.1.100

    // IPv6 地址 ::1 (即 0:0:0:0:0:0:0:1)
    let v6 = Ipv6Addr::new(0, 0, 0, 0, 0, 0, 0, 1);
    println!("{v6}"); // ::1

    // 3. 常用判断方法
    let loopback: IpAddr = "127.0.0.1".parse().expect("解析失败");
    println!("is_loopback = {}", loopback.is_loopback()); // is_loopback = true
    println!("is_ipv4 = {}", loopback.is_ipv4()); // is_ipv4 = true

    // is_private 只定义在 Ipv4Addr 上, 需要先取出 IPv4 变体
    let private: IpAddr = "192.168.1.1".parse().expect("解析失败");
    if let IpAddr::V4(v4) = &private {
        println!("is_private = {}", v4.is_private()); // is_private = true
    }

    // 4. 匹配具体的 IPv4 变体
    if let IpAddr::V4(v4) = private {
        println!("octets = {:?}", v4.octets()); // octets = [192, 168, 1, 1]
    }
}
```

#### SocketAddr

`SocketAddr` 是 "IP:端口" 的组合, 可以用一个字符串直接解析

```rust
use std::net::{IpAddr, SocketAddr};

fn main() {
    // 1. 字符串解析 "IP:端口"
    let addr: SocketAddr = "127.0.0.1:8080".parse().expect("解析失败");
    println!("{addr}"); // 127.0.0.1:8080

    // 2. 获取 IP 和端口
    println!("ip = {}", addr.ip()); // ip = 127.0.0.1
    println!("port = {}", addr.port()); // port = 8080

    // 3. 手动构造
    let ip: IpAddr = "127.0.0.1".parse().expect("解析失败");
    let addr2 = SocketAddr::new(ip, 8080);
    println!("{addr2}"); // 127.0.0.1:8080

    // 4. 判断 IPv4 还是 IPv6 (IPv6 用 [::1]:8080 这种写法)
    let v6: SocketAddr = "[::1]:8080".parse().expect("解析失败");
    println!("is_ipv6 = {}", v6.is_ipv6()); // is_ipv6 = true
}
```

### TCP 服务器

使用 [TcpListener](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html) 创建 TCP 服务器

| 方法                                                                                           | 作用                             |
| :--------------------------------------------------------------------------------------------- | :------------------------------- |
| [bind](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html#method.bind)                 | 绑定地址和端口(监听)             |
| [accept](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html#method.accept)             | 阻塞等待客户端连接               |
| [incoming](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html#method.incoming)         | 客户端连接的迭代器               |
| [local_addr](https://rustwiki.org/zh-CN/std/net/struct.TcpListener.html#method.local_addr)     | 获取监听的地址                   |

```rust
use std::io::{Read, Write};
use std::net::TcpListener;

fn main() {
    // bind: 绑定地址, 端口 0 表示由系统分配空闲端口
    let listener = TcpListener::bind("127.0.0.1:0").expect("绑定失败");
    let addr = listener.local_addr().expect("获取地址失败");
    println!("服务器监听: {addr}");

    // accept: 阻塞等待一个客户端连接
    // 返回 (TcpStream, SocketAddr): 连接流 和 客户端地址
    let (mut stream, client_addr) = listener.accept().expect("接受连接失败");
    println!("客户端已连接: {client_addr}");

    // 读取客户端发来的数据
    let mut buf = [0u8; 1024];
    let n = stream.read(&mut buf).expect("读取失败");
    println!("收到: {}", String::from_utf8_lossy(&buf[..n]));

    // 原样回复客户端(回显)
    stream.write_all(&buf[..n]).expect("写入失败");
}
```

::: danger 注意点
`accept` 是**阻塞**的, 一次只能处理一个客户端, 真正的服务器会在循环中不断 `accept`。
上面示例处理一次连接就退出, 是为了演示方便
:::

### TCP 客户端

使用 [TcpStream](https://rustwiki.org/zh-CN/std/net/struct.TcpStream.html) 连接服务器

| 方法                                                                                           | 作用                             |
| :--------------------------------------------------------------------------------------------- | :------------------------------- |
| [connect](https://rustwiki.org/zh-CN/std/net/struct.TcpStream.html#method.connect)             | 连接服务器(返回 Result)          |
| [read](https://rustwiki.org/zh-CN/std/io/trait.Read.html#method.read)                          | 读取数据(Read trait)             |
| [write_all](https://rustwiki.org/zh-CN/std/io/trait.Write.html#method.write_all)               | 写入数据(Write trait)            |
| [set_read_timeout](https://rustwiki.org/zh-CN/std/net/struct.TcpStream.html#method.set_read_timeout) | 设置读取超时, 防止一直阻塞       |

经典场景: 一个程序内同时启动服务器和客户端, 完成一次通信(回显)

```rust
use std::io::{Read, Write};
use std::net::{TcpListener, TcpStream};
use std::thread;

fn main() {
    // 1. 在子线程中启动服务器
    let listener = TcpListener::bind("127.0.0.1:0").expect("绑定失败");
    let addr = listener.local_addr().expect("获取地址失败");

    let server = thread::spawn(move || {
        // 接收一个连接
        let (mut stream, _) = listener.accept().expect("接受连接失败");

        // 读取客户端数据, 原样返回(回显)
        let mut buf = [0u8; 1024];
        let n = stream.read(&mut buf).expect("读取失败");
        stream.write_all(&buf[..n]).expect("写入失败");
    });

    // 2. 主线程作为客户端连接服务器
    let mut stream = TcpStream::connect(addr).expect("连接失败");
    stream.write_all(b"hello server").expect("发送失败");

    // 3. 读取服务器的回显
    let mut buf = [0u8; 1024];
    let n = stream.read(&mut buf).expect("读取失败");
    println!("服务器回显: {}", String::from_utf8_lossy(&buf[..n])); // 服务器回显: hello server

    // 4. 等待服务器线程结束
    server.join().expect("服务器线程失败");
}
```

### UDP

UDP 是**无连接**的协议, 使用 [UdpSocket](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html) 发送/接收数据报

| 方法                                                                                           | 作用                             |
| :--------------------------------------------------------------------------------------------- | :------------------------------- |
| [bind](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html#method.bind)                   | 绑定地址和端口                   |
| [send_to](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html#method.send_to)             | 发送数据到指定地址               |
| [recv_from](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html#method.recv_from)         | 接收数据(返回 数据 和 来源地址)  |
| [connect](https://rustwiki.org/zh-CN/std/net/struct.UdpSocket.html#method.connect)             | 只和指定地址通信(之后可用 send/recv) |

```rust
use std::net::UdpSocket;

fn main() {
    // 1. 创建两个 socket: 一个当服务器, 一个当客户端
    let server = UdpSocket::bind("127.0.0.1:0").expect("绑定失败");
    let client = UdpSocket::bind("127.0.0.1:0").expect("绑定失败");

    let server_addr = server.local_addr().expect("获取地址失败");
    println!("服务器地址: {server_addr}");

    // 2. 客户端发送数据
    client.send_to(b"hello udp", server_addr).expect("发送失败");

    // 3. 服务器接收数据
    // recv_from 返回: (收到的字节数, 发送方地址)
    let mut buf = [0u8; 1024];
    let (n, from) = server.recv_from(&mut buf).expect("接收失败");
    println!("收到 {n} 字节, 来自 {from}"); // 收到 9 字节, 来自 127.0.0.1:xxxxx
    println!("内容: {}", String::from_utf8_lossy(&buf[..n])); // 内容: hello udp
}
```

### 相关开源库

标准库的 `std::net` 只提供最底层的 TCP/UDP, 实际开发中常常使用更高级的库:

- [reqwest](https://crates.io/crates/reqwest): 最流行的 HTTP 客户端, 支持 JSON/重定向等
- [ureq](https://crates.io/crates/ureq): 轻量级同步 HTTP 客户端
- [tokio](https://crates.io/crates/tokio): 异步运行时, 高性能网络应用的事实标准

```rust
// Cargo.toml 添加依赖:
// [dependencies]
// reqwest = { version = "0.12", features = ["blocking"] }

fn main() {
    // reqwest: 发送一个 HTTP GET 请求
    let body = reqwest::blocking::get("https://httpbin.org/get")
        .expect("请求失败")
        .text()
        .expect("读取响应失败");
    println!("{body}");
}
```
