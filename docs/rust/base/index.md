## 介绍

Rust 是一种系统级编程语言, 设计用于开发高性能和可靠的应用程序

## 建议

并不推荐新手直接学习 Rust, 建议先学习 c 语言, 有了基础之后再学习 Rust

## Why Rust?

- 底层语言: 编译型语言, 性能与C/CPP是一个等级的
- 强大易用: 兼具编译型语言(如C)的控制力与解释型语言(如JS)的易用性
- 内存安全: "编译通过就能运行", 且不用牺牲性能
- 生态强大: 工具链齐全(rustup/cargo/rustfmt/rust-analyzer)
- 用途广泛: Web服务端/Web Assembly/命令行工具/桌面GUI软件/甚至嵌入式
