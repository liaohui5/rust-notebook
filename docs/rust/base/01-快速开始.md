## hello world

1. 新建 `main.rs`
2. 输入如下代码

```rs
fn main() {
  println!("hello world");
}
```

3. 编译 & 运行

```sh
# 编译
rustc ./main.rs

# 执行
./main # ./main.exe (on windows)
```

## 注释

```rs
fn main() {
  // 输出一个 hello world 到控制台
  println!("hello world")

  /*
  多行注释
  多行注释
  */
}
```
