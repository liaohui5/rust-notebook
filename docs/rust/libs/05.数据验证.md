## 数据验证

数据验证是软件开发工程中的重要技能, 因此会有许多不同的解决方案, Rust 生态中, 知名的数据验证库有

- [validator](https://crates.io/crates/validator)
- [garde](https://crates.io/crates/garde)
- [schemars](https://crates.io/crates/schemars)
- [jsonschema](https://crates.io/crates/jsonschema)
- [serde_valid](https://crates.io/crates/serde_valid)
- [zod-rs](https://zod.rs/)

## validator(推荐)

注意安装依赖:

- 为了使用正则表达式来模糊匹配: `cargo add regex@1.13`
- 为了性能别重复编译正则表达式: `cargo add lazy_static@1.5`, 或者手动使用 [std::sync::OnceLock](https://rustwiki.org/zh-CN/std/sync/struct.OnceLock.html)/[std::sync::LazyLock](https://rustwiki.org/zh-CN/std/sync/struct.LazyLock.html)
- 为了验证宏能够使用正则表达式: `cargo add validator@0.20 -F regex`

```rust
use lazy_static::lazy_static;
use regex::Regex;
use validator::{Validate, ValidationError, ValidationErrors};

lazy_static! {
    // 这个正则表达式只会编译一次
    static ref PASSWORD_REGEXP: Regex = Regex::new(r"^[A-Za-z0-9]+$").unwrap();
}

#[derive(Debug, Validate)]
struct RegisterForm {
    // 1.length 字符串长度 + custom 自定义验证函数(注: 这个验证函数必须返回一个 Result)
    #[validate(length(min = 3, max = 20), custom(function = "check_username"))]
    username: String,

    // 2.email 邮箱格式
    #[validate(email(message = "邮箱格式不正确"))]
    email: String,

    // 3.password 密码长度 + regex 正则表达式
    #[validate(
        length(min = 6, max = 32, message = "密码长度必须在 8 到 32 之间"),
        regex(path = *PASSWORD_REGEXP, message = "密码只能包含数字和大小写英文字母")
    )]
    password: String,

    // 4.确认密码必须和 password 字段一致
    #[validate(must_match(other = "password", message = "两次输入的密码不一致"))]
    password_confirm: String,

    // 5.数字范围
    #[validate(range(min = 18, max = 120, message = "年龄必须在 18 到 120 之间"))]
    age: u8,

    // 6.嵌套验证: 会递归验证 Address 内部的规则
    #[validate(nested)]
    address: Address,
}

// 自定义验证函数: 用户名不能为空，且不能包含空格
fn check_username(username: &str) -> Result<(), ValidationError> {
    if username.trim().is_empty() {
        return Err(ValidationError::new("username_empty"));
    }

    if username.contains(' ') {
        let mut err = ValidationError::new("username_has_space");
        err.message = Some("用户名不能包含空格".into());
        return Err(err);
    }

    Ok(())
}

#[derive(Debug, Validate)]
struct Address {
    #[validate(length(min = 1, message = "城市不能为空"))]
    city: String,

    #[validate(length(min = 5, max = 10, message = "邮编长度必须在 5 到 10 之间"))]
    zip: String,
}

fn print_errors(errors: &ValidationErrors) {
    for (field, field_errors) in errors.field_errors() {
        for error in field_errors {
            println!(
                "字段 `{}` 验证失败: code={}, message={:?}",
                field, error.code, error.message
            );
        }
    }
}

fn main() {
    // 合法数据
    let form = RegisterForm {
        username: "alice".into(),
        email: "alice@example.com".into(),
        password: "secret123".into(),
        password_confirm: "secret123".into(),
        age: 25,
        address: Address {
            city: "Beijing".into(),
            zip: "100000".into(),
        },
    };

    match form.validate() {
        Ok(()) => println!("✅ 验证通过"),
        Err(errors) => print_errors(&errors),
    }

    // 非法数据
    let bad_form = RegisterForm {
        username: "alice smith".into(),
        email: "not-an-email".into(),
        password: "123@456".into(),
        password_confirm: "456".into(),
        age: 16,
        address: Address {
            city: "".into(),
            zip: "123".into(),
        },
    };

    match bad_form.validate() {
        Ok(()) => println!("✅ 验证通过"),
        Err(errors) => print_errors(&errors),
    }
}
```

## serde_valid

注意安装依赖:

- `cargo add serde@1 -F derive`
- `cargo add serde_valid@3.2`

```rust
use serde::{Deserialize, Serialize};
use serde_valid::Validate;

// 0.必须实现 serde_valid::Validate trait
#[derive(Debug, Serialize, Deserialize, Validate)]
pub struct RegisterForm {
    // 1.length 字符串长度限制
    #[validate(min_length = 3)]
    #[validate(max_length = 20)]
    username: String,

    // 2.email 邮箱格式(手动写正则表达式)
    #[validate(pattern = r"^[^@\s]+@[^@\s]+\.[^@\s]+$")]
    email: String,

    // 3.password 密码长度 + regex 正则表达式
    #[validate(pattern = r"^[A-Za-z0-9]+$")]
    #[validate(max_length = 32)]
    #[validate(min_length = 8)]
    password: String,

    // 4.确认密码必须和 password 字段一致,
    // serde_valid 没有 matches 规则, 需要手动判断
    password_confirm: String,

    // 5.数字范围
    #[validate(minimum = 18)]
    #[validate(maximum = 120)]
    age: u8,

    // 6.嵌套验证: 会递归验证 Address 内部的规则
    #[validate]
    address: Address,
}

#[derive(Debug, Deserialize, Serialize, Validate)]
pub struct Address {
    // 城市: 从头到尾必须是英文字符
    #[validate(pattern = r"^\w+$$")]
    #[validate(min_length = 1)]
    city: String,

    // 邮政编码: 从头到尾必须是数字
    #[validate(pattern = r"^\d{5}$")]
    zip: String,
}

fn main() {
    println!("Hello, world!");
}
```

## zod-rs

如果你习惯使用 [zod](https://zod.dev/)(zod 是 typescript 写的, 是 JS 生态用来验证数据的库) 那么可以试着使用 zod-rs

注意安装依赖:

- `cargo add zod-rs@1.1`

::: code-group

```rust [不使用宏]
use serde::{Deserialize, Serialize};
use serde_json;
use zod_rs::prelude::*;

#[derive(Debug, Serialize, Deserialize)]
pub struct RegisterForm {
    username: String,
    email: String,
    password: String,
    password_confirm: String,
    age: u8,
    address: Option<Address>,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct Address {
    city: String,
    zip: String,
}

// 0.手动构建验证规则 schema(更灵活)
fn create_register_form_schema() -> zod_rs::ObjectSchema {
    object()
        .field("username", string().min(3).max(20))
        .field("email", string().email())
        .field("password", string().min(6).max(32).regex("^\\w+$"))
        .field("age", number().min(18.0).max(120.0).int())
        .field(
            "address", // 如何验证嵌套结构
            object()
                .field("city", string().min(1))
                .field("zip", string().regex("^\\d{6}$")),
        )
}

fn main() {
    // 表单数据(json 字符串)
    let json_value = serde_json::json!({
        "username": "alice",
        "email": "alice@example.com",
        "password": "secret123",
        "password_confirm": "secret123",
        "age": 25,
        "address": {
            "city": "Beijing",
            "zip": "100000"
        }
    });

    // 1.获取验证规则
    let zod_schema = create_register_form_schema();

    // 2.通过验证该规则直接验证
    match zod_schema.safe_parse(&json_value) {
        Ok(value) => {
            println!("验证成功: {value:?}");
        }
        Err(e) => {
            println!("验证失败: {e:?}");
        }
    };
}
```

use serde::{Deserialize, Serialize};
use serde_json;
use zod_rs::prelude::*;

#[derive(Debug, Serialize, Deserialize, ZodSchema)]
pub struct RegisterForm {
    #[zod(min_length(3), max_length(20))]
    username: String,

    #[zod(email)]
    email: String,

    #[zod(min_length(6), max_length(32), regex(r"^\w+$"))]
    password: String,

    // 没有匹配另外一个字段的规则需要手动验证
    password_confirm: String,

    #[zod(min(18.0), max(120.0), int)]
    age: u8,

    // 嵌套结构体，derive 宏会自动处理
    address: Option<Address>,
}

// 嵌套结构体, 也必须实现 ZodSchema
#[derive(Debug, Serialize, Deserialize, ZodSchema)]
pub struct Address {
    #[zod(min_length(1))]
    city: String,

    #[zod(regex(r"^\d{6}$"))]
    zip: String,
}

fn main() {
    // 1.表单数据(json Value)
    let json_value = serde_json::json!({
        "username": "alice",
        "email": "alice@example.com",
        "password": "secret123",
        "password_confirm": "secret123",
        "age": 25,
        "address": {
            "city": "Beijing",
            "zip": "100000"
        }
    });

        Ok(value) => {
            println!("验证成功: {value:?}");
        }
        Err(e) => {
            println!("验证失败: {e:?}");
        }
    }
