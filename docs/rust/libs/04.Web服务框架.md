## Rust 生态 web 开发库了解

- [axum](https://github.com/tokio-rs/axum) tokio 官方维护的 web 框架, 性能均衡, 无宏(新手友好), 可惜只有 Rustdoc 没有类似 actix/rocket 那样类似 `新手教程的文档`
- [actix](https://actix.rs) 异步支持, 性能战神, 文档齐全, 学习门槛高/actor异步模型/大量的宏(黑魔法)
- [rocket](https://rocket.rs/) Rust 生态 web 开发领取先驱, 文档齐全, 同时支持同步异步处理/易于学习&使用/功能更全面
- [salvo](https://salvo.rs/) 后起之秀, 正在积极开发中, 文档齐全, 中文友好, 提供脚手架 `cli` 支持前沿协议 `HTTP3`
- [summer-rs](https://summer-rs.github.io/zh/) 号称要做 Rust 版本的 spring-boot, 但是现在生态可用插件远远没有 spring 生态那么多, 但值得期待

由于 Rust 标准库本身并没有提供 HTTP 协议的实现, 所以有兴趣可以去学习下比较底层的库 [hyper.rs](https://hyper.rs/guides/1/),

## axum

由于 actix/rocket.rs 都有大量的黑魔法(宏), 所以这里以 axum 作为入门基础, 只要学会了这一个,
那么其他的框架也是类似的处理套路, 因为这些框架的目的就是要简化处理 HTTP 请求的流程

### 快速开始

::: code-group

```rust[main.rs]
use axum::{Router, routing};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 创建路由
    let router = create_app_router();

    // 监听端口
    let listener = TcpListener::bind("0.0.0.0:3000").await?;

    // 输出提示信息
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    // 启动服务
    axum::serve(listener, router).await?;

    Ok(())
}

// 创建 router
fn create_app_router() -> Router {
    let router = Router::new()
        // 设置路由的 路径 / 处理方法 / 处理函数
        .route("/", routing::get(index));

    router
}

// index 处理器
async fn index() -> &'static str {
    "Hello axum"
}
```

### 获取请求信息 Request

```rust
use axum::{
    Json, Router,
    body::Bytes,
    extract::{Multipart, Path, Query, Request},
    http::{HeaderMap, StatusCode},
    response::IntoResponse,
    routing,
};
use serde::{Deserialize, Serialize};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/req1/{id}/{name}", routing::get(handler1))
        .route("/req2", routing::get(handler2))
        .route("/req3", routing::post(handler3))
        .route("/req4", routing::post(handler4))
        .route("/req5", routing::post(handler5))
        .route("/req6", routing::get(handler6))
        .route("/req7", routing::get(handler7));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 获取路径参数
// 测试: curl http://127.0.0.1:3000/api/req1/9527/jerry
// 也可以绑定结构体：
// #[derive(Deserialize)]
// struct Req1Path { id: u32, name: String }
// async fn handler1(Path(Req1Path { id, name }): Path<Req1Path>) -> String { ... }
async fn handler1(Path((id, name)): Path<(u32, String)>) -> String {
    format!("id = {}, name = {:?}", id, name)
}

// 2. 查询参数
// 测试: curl http://127.0.0.1:3000/api/req2?page=1&size=20&keyword=rust
#[derive(Deserialize)]
struct SearchQuery {
    page: Option<u32>, // Option 表示可选参数, 未传则值为 None
    size: Option<u32>,
    keyword: String, // 没有 Option 表示必须参数, 不传则解析报错
}
async fn handler2(Query(sq): Query<SearchQuery>) -> String {
    format!(
        "page = {:?}, size = {:?}, keyword = {:?}",
        sq.page, sq.size, sq.keyword
    )
}

// 3. 表单数据(Content-Type: application/x-www-form-urlencoded)
// 测试命令:
// curl -X POST 'http://127.0.0.1:3000/api/req3' \
//   -H 'Content-Type: application/x-www-form-urlencoded' \
//   -d 'username=alice&password=123456'
#[derive(Deserialize)]
struct Req3Form {
    username: String,
    password: String,
    remember_me: Option<bool>, // 可选参数
}
async fn handler3(axum::Form(form): axum::Form<Req3Form>) -> String {
    format!(
        "username = {}, password = {}, remember_me = {:?}",
        form.username, form.password, form.remember_me
    )
}

// 4. JSON 数据(Content-Type: application/json)
// 测试命令:
// curl -X POST 'http://127.0.0.1:3000/api/req4' \
//     -H 'Content-Type: application/json' \
//     -d '{"name": "alice", "age": 20}'
#[derive(Deserialize, Serialize)]
struct Req4Json {
    name: String,
    age: u32,
}

async fn handler4(Json(payload): Json<Req4Json>) -> impl IntoResponse {
    Json(serde_json::json!({
        "message": "ok",
        "received_data": payload
    }))
}

// 5. 文件上传 (multipart/form-data)
// 注意需要开启 axum 的 multipart 功能: cargo add axum@0.8 -F multipart
// 请直接使用 postman/apifox/httpie 等图形化工具比较好测试
// https://httpie.io/
// https://hoppscotch.io/
async fn handler5(mut multipart: Multipart) -> Result<String, (StatusCode, String)> {
    let mut result = String::new();

    while let Some(field) = multipart
        .next_field()
        .await
        .map_err(|e| (StatusCode::BAD_REQUEST, e.to_string()))?
    {
        // 获取字段名(如: avatar_img)
        let field_name = field.name().unwrap_or("").to_string();

        // 获取文件名(如: rust.png)
        let file_name = field.file_name().unwrap_or("").to_string();

        // 获取文件mimetype(如: image/png)
        let content_type = field.content_type().unwrap_or("").to_string();

        // 获取文件大小(如: 41818, 单位: bytes)
        let data: Bytes = field
            .bytes()
            .await
            .map_err(|e| (StatusCode::BAD_REQUEST, e.to_string()))?;

        result.push_str(&format!(
            "field={}, filename={}, content_type={}, size={} bytes\n",
            field_name,
            file_name,
            content_type,
            data.len()
        ));

        // 如果要保存到磁盘：
        // tokio::fs::write(format!("uploads/{}", file_name), &data).await
        //     .map_err(|e| (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()))?;
    }

    Ok(result)
}

// 6. 请求头
// 测试命令:
// curl -X GET 'http://127.0.0.1:3000/api/req6' \
//     -H 'x-auth-token: mock-auth-token-string' \
//     -H 'user-agent: curl' \
async fn handler6(headers: HeaderMap) -> String {
    let mut out = String::new();

    // 获取单个 header
    if let Some(ua) = headers.get("user-agent") {
        out.push_str(&format!("user-agent = {:?}\n", ua));
    }

    // 遍历所有 header, 包括自定义的 header 字段
    for (k, v) in headers.iter() {
        out.push_str(&format!("{}: {:?}\n", k, v));
    }

    out
}

// 7. 原始 Request 实例
// 测试命令:
// curl http://127.0.0.1:3000/api/req7
async fn handler7(req: Request) -> impl IntoResponse {
    let method = req.method().clone();
    let uri = req.uri().clone();
    let version = req.version();
    let headers = req.headers().clone();

    // 注意：Request 被消费后 body 就没了，所以要在销毁前使用
    let body_bytes = axum::body::to_bytes(req.into_body(), usize::MAX)
        .await
        .unwrap_or_default();

    let info = format!(
        "method = {}\nuri = {}\nversion = {:?}\nheaders = {:?}\nbody = {:?}",
        method,
        uri,
        version,
        headers,
        String::from_utf8_lossy(&body_bytes)
    );

    (StatusCode::OK, info)
}
```

### 设置响应信息 Response

响应根据数据组织方式可以分为三类: `字符串` 和 `二进制数据流` 和 `重定向`

- 字符串: text/html/json 等等不同格式的字符串
- 二进制数据流: 图片/视频等静态资源文件下载

::: code-group

```rust [文本字符串]
use axum::{Json, Router, routing};
use serde::Serialize;
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/str1", routing::get(str1_handler))
        .route("/str2", routing::get(str2_handler))
        .route("/json", routing::get(json_handler))
        .route("/html", routing::get(html_handler));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 响应纯文本, 自动设置响应 header
// Content-Type: text/plain; charset=utf-8
async fn str1_handler() -> String {
    String::from("raw string")
}

async fn str2_handler() -> &'static str {
    "raw &str"
}

// 2. 响应 json, 自动设置响应 header
// Content-Type: application/json
#[derive(Serialize)]
struct User {
    id: u32,
    name: String,
}
async fn json_handler() -> Json<User> {
    // 用 Json 包装, axum 自动序列化并设置 header
    // 也可以用 serde 提供的 json! 宏：
    // Json(serde_json::json!({ "id": 1, "name": "alice" }))
    Json(User {
        id: 1,
        name: "alice".to_string(),
    })
}

// 3. 响应 HTML: 自动设置响应头:
// Content-Type: text/html
async fn html_handler() -> axum::response::Html<&'static str> {
    axum::response::Html("<h1>Hello, axum!</h1>")
}
```

```rust [二进制数据流]
use axum::{
    Router,
    body::Body,
    http::StatusCode,
    response::{IntoResponse, Response},
    routing,
};
use tokio::{
    fs::{self, File},
    net::TcpListener,
};

use axum_extra;
use tokio_util;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/down1", routing::get(download_handler1))
        .route("/down2", routing::get(download_handler2))
        .route("/down3", routing::get(download_handler3));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 下载小文件: 一次性将文件内容读取到内存, 然后直接发回客户端
// 注意需要安装依赖, 并开启 attachment 和 file-stream 功能
// cargo add axum-extra@0.12 -F attachment,file-stream
async fn download_handler1() -> axum_extra::response::Attachment<Vec<u8>> {
    // 异步读取文件内容(一次性读取所有)
    let src_filename = "Cargo.toml";
    let content = fs::read(src_filename).await.unwrap_or_default();

    // 构建 Attachment 响应对象
    axum_extra::response::Attachment::new(content)
        // 设置下载时显示的文件名
        .filename(src_filename)
        // 设置下载时显示的 mime-type
        .content_type("application/toml")
}

// 2. 下载大文件: 边读边传, 避免文件过大占用过多内存
// 注意需要安装依赖: cargo add tokio-util@0.7
async fn download_handler2() -> Result<Response, (StatusCode, String)> {
    // 注意这个文件必须存在
    let filename = "demo.mp4";

    // 1.异步打开文件句柄
    let file = File::open(filename)
        .await
        .map_err(|e| (StatusCode::NOT_FOUND, format!("filt not exists: {e}")))?;

    // 2.流式读取文件内容
    let stream = tokio_util::io::ReaderStream::new(file);

    // 3.构建响应对象, 响应头 content-type 为 application/octet-stream
    let file_stream_resp = axum_extra::response::FileStream::new(stream).file_name(filename);

    Ok(file_stream_resp.into_response())
}

// 3. 下载大文件: 边读边传, 与 download_handler2 不同, 不需要 tokio-util
// 是 tokio::fs::File 和 Body::from_stream 构造 body 然后响应, 这种方式的
// 的好处就是可以设置响应内容的 mime-type
async fn download_handler3() -> Result<axum_extra::response::Attachment<Body>, (StatusCode, String)>
{
    // 注意这个文件必须存在
    let filename = "demo.mp4";

    // 1.异步打开文件句柄
    let file = File::open(filename)
        .await
        .map_err(|e| (StatusCode::NOT_FOUND, format!("filt not exists: {e}")))?;

    // 2.流式读取文件内容
    let stream = tokio_util::io::ReaderStream::new(file);

    // 3.构造响应对象的 body 部分
    let body = Body::from_stream(stream);

    // 4.注意与 download_handler2 的不同
    // 4.1)使用 axum_extra::response::Attachment 构造响应而不是 axum_extra::response::FileStream
    // 4.2)响应头: content-type 为: video/mp4
    let attachment = axum_extra::response::Attachment::new(body)
        .filename(filename)
        .content_type("video/mp4");

    Ok(attachment)
}
```

```rust [重定向]
use axum::{Router, response, routing};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/test", routing::get(test_handler))
        .route("/303", routing::get(redirect_handler1))
        .route("/307", routing::get(redirect_handler2))
        .route("/308", routing::get(redirect_handler3));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 0. 被重定向的路由
async fn test_handler() -> String {
    String::from("hello axum")
}

// 1. 默认重定向, 测试命令: curl -i http://127.0.0.1:3000/api/303
async fn redirect_handler1() -> response::Redirect {
    // HTTP/1.1 303 See Other
    response::Redirect::to("/api/test")
}

// 2. 临时重定向, 测试命令: curl -i http://127.0.0.1:3000/api/307
async fn redirect_handler2() -> response::Redirect {
    // HTTP/1.1 307 Temporary Redirect
    response::Redirect::temporary("/api/test")
}

// 3. 永久重定向, 测试命令: curl -i http://127.0.0.1:3000/api/308
async fn redirect_handler3() -> response::Redirect {
    // HTTP/1.1 308 Permanent Redirect
    response::Redirect::permanent("/api/test")
}

// 注意: 根据HTTP/1.0 的规范:
// 临时重定向状态码是: 301
// 永久重定向状态码是: 202
// 而 axum 响应使用的是 HTTP/1.1 的规范
```

### 数据绑定与验证

需要依赖 `axum-valid` 和 `validator`, 注意版本, 有的版本可能冲突(比如: axum-valid@0.25 与 validator@0.21 冲突)

- 安装 axum-valid: `cargo add axum-valid@0.25`
- 安装 validator: `cargo add validator@0.20 -F derive`

更多的数据验证规则请查看 [数据验证章节](/rust/libs/05.数据验证) validator 部分

```rust
use axum::{
    Json,
    Router,
    extract::{Form, Query}, // 注意：Form 从 axum::extract 导入
    routing,
};
use tokio::net::TcpListener;

use axum_valid::Valid; // version: 0.25
use serde::{Deserialize, Serialize};
```

```rs [config.rs]
pub fn init_config() -> Result<AppConfig, Box<dyn Error>> {
    // 1. 解析命令行参数获取 env 并验证, 只允许值为 dev/test/prod
    let app_env = std::env::var("APP_ENV").unwrap_or(String::from("dev"));
    let allowd_envs = vec!["dev", "prod", "test"];

    if !allowd_envs.iter().any(|v| v.eq(&app_env)) {
        let err_msg = format!("APP_ENV only allowed to be {}", allowd_envs.join(","));
        return Err(err_msg.into());
    }

    // 2. 分层加载配置文件, 后者覆盖前者
    println!("{app_env} config file loading...");
    let base_cfg_path = "config/default.toml";
    let env_cfg_path = format!("config/{}.toml", app_env);
    let cfg = load_configs(base_cfg_path, &env_cfg_path)?;

    // 3. 解析配置文件
    let config = cfg.try_deserialize::<AppConfig>()?;
    Ok(config)
}

// 分层加载配置文件
pub fn load_configs(default_cfg_path: &str, env_cfg_path: &str) -> Result<Config, Box<dyn Error>> {
    // 1. 构建配置构建器
    let mut config_builder = Config::builder();
    let base_cfg_file = File::with_name(default_cfg_path)
        .format(FileFormat::Toml)
        .required(true);
    config_builder = config_builder.add_source(base_cfg_file);

    // 2.加载特定 env 环境的配置文件(优先级高于 default.toml)
    let env_cfg_file = File::with_name(env_cfg_path)
        .format(FileFormat::Toml)
        .required(false);
    config_builder = config_builder.add_source(env_cfg_file);

    // 4. 构建 & 返回结果
    let cfg = config_builder.build()?;
    Ok(cfg)
}
```

```rust [logger.rs]
use tracing_appender::non_blocking::WorkerGuard;
use tracing_subscriber::layer::SubscriberExt;
use tracing_subscriber::util::SubscriberInitExt;
use tracing_subscriber::{self, EnvFilter, fmt};

// TODO: 实际项目中, 应该传入 AppConfig 实例对象
// 1. 用配置文件管理 logs_save_path
// 2. 用配置文件管理 日志过滤等级

pub fn init_logger(logs_save_path: &str) -> WorkerGuard {
    // 0.确保目录存在(应该用配置文件来管理, 先这样实现)
    std::fs::create_dir_all(logs_save_path).expect("failed to create logs dir");

    // 1.使用 export RUST_LOG=debug 这样的环境变量来控制日志过滤级别
    // 1.1) unwrap_or_else 中的这个默认值应该用 config + 配置文件来控制
    let env_filter_layer = tracing_subscriber::EnvFilter::try_from_default_env()
        .unwrap_or_else(|_| EnvFilter::new("info"));

    // 2.创建写入文件的 layer
    // 2.1)创建按天滚动的文件 appender, 生成的文件路径类似于: logs/app.log.2026-09-24
    // 2.2)使用 non_blocking 包装文件写入器, 避免阻塞主线程
    // 2.3)注意写入文件中的是 json 格式, 方便后续编程处理
    let file_appender = tracing_appender::rolling::daily("logs", "app.log");
    let (async_file_writer, guard) = tracing_appender::non_blocking(file_appender);
    let file_writer_layer = fmt::layer()
        .json()
        .with_writer(async_file_writer)
        .with_ansi(false)
        .with_target(true)
        .with_file(true)
        .with_thread_ids(true);

    // 3.创建写入 stdout 的 layer
    // 3.1) 注意设置输出到 stdout 的信息字段(并不是 JSON 格式的)
    let console_writer_layer = fmt::layer()
        .with_writer(std::io::stdout)
        .with_target(true)
        .with_thread_names(true)
        .with_file(true)
        .with_ansi(true);

    // 4.初始化
    // 4.1) 注意处理错误
    tracing_subscriber::registry()
        .with(env_filter_layer)
        .with(file_writer_layer)
        .with(console_writer_layer)
        .try_init()
        .expect("failed to init logger");

    // 5.注意要返回这个 guard, 否则这个函数执行完
    // guard 就被释放了, 那么就不会将内容写入到文件中了
    // 所以必须要返回它, 让他的生命周期延长至 main 函数结束
```

```rust{8-26,37-42,46-58,74-84}[快速入门:URL参数注解示例]
use serde::{Deserialize, Serialize};
use tokio::net::TcpListener;
use utoipa::{IntoParams, OpenApi, ToSchema};
use utoipa_axum::{router::OpenApiRouter, routes};

// 注: param 中的内容是用来定义参数验证的, 它仅在 swagger ui 中生效
// 比如 limit 超过 100 就会无法通过 swagger 点击 execute 发起请求
// 如果要做服务端参数验证, 不能通过这个宏来做, 要使用 validator
// param 上方的3斜线开头的是字段说明

/// 搜索参数(作为 Query String 使用)
#[derive(Debug, Clone, Serialize, Deserialize, ToSchema, IntoParams)]
pub struct SearchQuery {
    /// 页码
    #[param(default = 1, minimum = 1)]
    pub page: u32,

    /// 每页数量
    #[param(default = 10, minimum = 1, maximum = 100)]
    pub limit: u32,

    /// 搜索关键字
    pub keyword: Option<String>,
}

/// 统一响应(仅用于演示)
#[derive(Debug, Clone, Serialize, Deserialize, ToSchema)]
pub struct SearchResponse {
    pub page: u32,
    pub limit: u32,
    pub keyword: String,
    pub matches: Vec<String>,
}

// 1.定义 ApiDoc, 注意 openapi 宏的 paths 参数是必选项, components(schemas) 是
// 可选的, 它用于定义 swagger webui 的 Schemas 部分的内容, 这个宏会自动实现
// openapi 方法, 返回一个 openapi::OpenApi 实例, 它是 utoipa 的依赖的 struct
#[derive(OpenApi)]
#[openapi(paths(get_search), components(schemas(SearchQuery, SearchResponse)))]
struct ApiDoc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 2.使用 OpenApiRouter::with_openapi 来创建 axum::Router 实例, 而不是
    // 直接使用 axum::Router::new() 来创建, with_openapi 返回一个元组
    // router: 是一个 axum::Router 实例
    // api: 是一个编译后的字符串
    let (router, api) = OpenApiRouter::with_openapi(ApiDoc::openapi())
        .routes(routes!(get_search)) // 注意需要用 routes! 序列化 handler 宏标注信息
        .split_for_parts();

    // 4.创建 SwaggerUi::new 返回一个 axum::Router 实例, 提供两个路由
    // /swagger: 是 swagger-ui 的 html 网页内容
    // /swagger/openapi.json: 会响应 api 的字符串内哦让
    // 注: 如果生产环境不想要这两个路由, 可以通过配置文件动态控制, 不 merge 到 app_router
    let swagger_router = SwaggerUi::new("/swagger").url("/swagger/openapi.json", api.clone());

    // 5.合并所有 router 并启动监听
    let app_router = router.merge(swagger_router);
    let listener = TcpListener::bind("127.0.0.1:3000").await.unwrap();

    let addr = listener.local_addr()?;
    println!("axum:          http://{}", addr);
    println!("openapi:       http://{}/swagger", addr);
    println!("swagger webui: http://{}/swagger/openapi.json", addr);

    axum::serve(listener, app_router).await?;

    Ok(())
}

#[utoipa::path(
    get,                  // 请求方式
    path = "/search",     // 请求路径
    params(SearchQuery),  // 请求参数
    responses(            // 响应示例
        (status = 200, description = "查询成功", body = SearchResponse),
        (status = 400, description = "请求参数错误")
    )
)]
pub async fn get_search(Query(params): Query<SearchQuery>) -> impl IntoResponse {
    axum::Json(SearchResponse {
        page: params.page,
        limit: params.limit,
        keyword: params.keyword.unwrap_or_default(),
        matches: vec![
            format!("rust result {} on page {}", 1, params.page),
            format!("rust result {} on page {}", 2, params.page),
```

```rust{32-59}[Form 表单注解示例]
use axum::{extract::Form, response::IntoResponse};

use utoipa::{OpenApi, ToSchema};

/// 搜索参数(作为 application/x-www-form-urlencoded 表单使用)
#[derive(Debug, Clone, Serialize, Deserialize, ToSchema)]
pub struct SearchForm {
    /// 页码
    #[schema(default = 1, minimum = 1)]
    pub page: u32,

    /// 每页数量
    #[schema(default = 10, minimum = 1, maximum = 100)]
    pub limit: u32,

    /// 搜索关键字
    pub keyword: String,

#[derive(Debug, Clone, Serialize, Deserialize, ToSchema)]
pub struct SearchResponse {
    pub page: u32,
    pub limit: u32,
    pub keyword: String,
    pub matches: Vec<String>,
}

/// POST /search 示例：使用 Form 提取 URL-encoded 表单
///
/// 请求体是 `page=1&limit=10&keyword=rust`，
/// Content-Type 为 `application/x-www-form-urlencoded`。
#[utoipa::path(
    post,
    path = "/search",
    request_body = SearchForm, // 注意与 GET 请求的区别
    responses(
        (status = 200, description = "查询成功", body = SearchResponse),
        (status = 400, description = "请求参数错误")
    )
)]
pub async fn post_search(Form(params): Form<SearchForm>) -> impl IntoResponse {
    axum::Json(SearchResponse {
        page: params.page,
        limit: params.limit,
        keyword: params.keyword,
        matches: vec![
            format!("rust result {} on page {}", 1, params.page),
            format!("rust result {} on page {}", 2, params.page),
        ],
    })
}

#[derive(OpenApi)]
#[openapi(paths(post_search,), components(schemas(SearchForm, SearchResponse)))]
struct ApiDoc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let (router, api) = OpenApiRouter::with_openapi(ApiDoc::openapi())
        .routes(routes!(post_search))
        .split_for_parts();

    let swagger_router = SwaggerUi::new("/swagger").url("/swagger/openapi.json", api.clone());

    let app_router = router.merge(swagger_router);

    let addr = listener.local_addr()?;

    println!("axum:          http://{}", addr);
    println!("openapi:       http://{}/swagger", addr);
    println!("swagger webui: http://{}/swagger/openapi.json", addr);

    axum::serve(listener, app_router).await?;

}
```
