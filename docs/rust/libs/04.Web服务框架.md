## Rust 生态 web 开发库了解

- [axum](https://github.com/tokio-rs/axum) tokio 官方维护的 web 框架, 性能均衡, 无宏(新手友好), 可惜只有 Rustdoc 没有类似 actix/rocket 那样类似 `新手教程的文档`
- [actix](https://actix.rs) 异步支持, 性能战神, 文档齐全, 学习门槛高/actor异步模型/大量的宏(黑魔法)
- [rocket](https://rocket.rs/) Rust 生态 web 开发领取先驱, 文档齐全, 同时支持同步异步处理/易于学习&使用/功能更全面
- [salvo](https://salvo.rs/) 后起之秀, 正在积极开发中, 文档齐全, 中文友好, 提供脚手架 `cli` 支持前沿协议 `HTTP3`
- [summer-rs](https://summer-rs.github.io/zh/) 号称要做 Rust 版本的 spring-boot, 但是现在生态可用插件远远没有 spring 生态那么多, 但值得期待

由于 Rust 标准库本身并没有提供 HTTP 协议的实现, 所以有兴趣可以去学习下比较底层的库 [hyper.rs](https://hyper.rs/guides/1/),

## axum

由于 actix/rocket.rs 都有大量的黑魔法(宏), 所以这里以 axum 作为入门基础, 只要学会了这一个,
那么其他的框架也是类似的处理套路, 因为这些框架的目的就是要简化处理 HTTP 请求的流程

### 快速开始

::: code-group

```rust[main.rs]
use axum::{Router, routing};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 创建路由
    let router = create_app_router();

    // 监听端口
    let listener = TcpListener::bind("0.0.0.0:3000").await?;

    // 输出提示信息
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    // 启动服务
    axum::serve(listener, router).await?;

    Ok(())
}

// 创建 router
fn create_app_router() -> Router {
    let router = Router::new()
        // 设置路由的 路径 / 处理方法 / 处理函数
        .route("/", routing::get(index));

    router
}

// index 处理器
async fn index() -> &'static str {
    "Hello axum"
}
```

### 获取请求信息 Request

```rust
use axum::{
    Json, Router,
    body::Bytes,
    extract::{Multipart, Path, Query, Request},
    http::{HeaderMap, StatusCode},
    response::IntoResponse,
    routing,
};
use serde::{Deserialize, Serialize};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/req1/{id}/{name}", routing::get(handler1))
        .route("/req2", routing::get(handler2))
        .route("/req3", routing::post(handler3)) // 改成 post 更符合 form 场景
        .route("/req4", routing::post(handler4)) // 改成 post 更符合 json 场景
        .route("/req5", routing::post(handler5)) // 文件上传用 post
        .route("/req6", routing::get(handler6))
        .route("/req7", routing::get(handler7));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 获取路径参数
// 测试: curl http://127.0.0.1:3000/api/req1/9527/jerry
// 也可以绑定结构体：
// #[derive(Deserialize)]
// struct Req1Path { id: u32, name: String }
// async fn handler1(Path(Req1Path { id, name }): Path<Req1Path>) -> String { ... }
async fn handler1(Path((id, name)): Path<(u32, String)>) -> String {
    format!("id = {}, name = {:?}", id, name)
}

// 2. 查询参数
// 测试: curl http://127.0.0.1:3000/api/req2?page=1&size=20&keyword=rust
#[derive(Deserialize)]
struct SearchQuery {
    page: Option<u32>, // Option 表示可选参数, 未传则值为 None
    size: Option<u32>,
    keyword: String, // 没有 Option 表示必须参数, 不传则解析报错
}
async fn handler2(Query(sq): Query<SearchQuery>) -> String {
    format!(
        "page = {:?}, size = {:?}, keyword = {:?}",
        sq.page, sq.size, sq.keyword
    )
}

// 3. 表单数据(Content-Type: application/x-www-form-urlencoded)
// 测试命令:
// curl -X POST 'http://127.0.0.1:3000/api/req3' \
//   -H 'Content-Type: application/x-www-form-urlencoded' \
//   -d 'username=alice&password=123456'
#[derive(Deserialize)]
struct Req3Form {
    username: String,
    password: String,
    remember_me: Option<bool>, // 可选参数
}
async fn handler3(axum::Form(form): axum::Form<Req3Form>) -> String {
    format!(
        "username = {}, password = {}, remember_me = {:?}",
        form.username, form.password, form.remember_me
    )
}

// 4. JSON 数据(Content-Type: application/json)
// 测试命令:
// curl -X POST 'http://127.0.0.1:3000/api/req4' \
//     -H 'Content-Type: application/json' \
//     -d '{"name": "alice", "age": 20}'
#[derive(Deserialize, Serialize)]
struct Req4Json {
    name: String,
    age: u32,
}

async fn handler4(Json(payload): Json<Req4Json>) -> impl IntoResponse {
    Json(serde_json::json!({
        "message": "ok",
        "received_data": payload
    }))
}

// 5. 文件上传 (multipart/form-data)
// 注意需要开启 axum 的 multipart 功能: cargo add axum -F multipart
// 请直接使用 postman/apifox/httpie 等图形化工具比较好测试
// https://httpie.io/
// https://hoppscotch.io/
async fn handler5(mut multipart: Multipart) -> Result<String, (StatusCode, String)> {
    let mut result = String::new();

    while let Some(field) = multipart
        .next_field()
        .await
        .map_err(|e| (StatusCode::BAD_REQUEST, e.to_string()))?
    {
        // 获取字段名(如: avatar_img)
        let field_name = field.name().unwrap_or("").to_string();

        // 获取文件名(如: rust.png)
        let file_name = field.file_name().unwrap_or("").to_string();

        // 获取文件mimetype(如: image/png)
        let content_type = field.content_type().unwrap_or("").to_string();

        // 获取文件大小(如: 41818, 单位: bytes)
        let data: Bytes = field
            .bytes()
            .await
            .map_err(|e| (StatusCode::BAD_REQUEST, e.to_string()))?;

        result.push_str(&format!(
            "field={}, filename={}, content_type={}, size={} bytes\n",
            field_name,
            file_name,
            content_type,
            data.len()
        ));

        // 如果要保存到磁盘：
        // tokio::fs::write(format!("uploads/{}", file_name), &data).await
        //     .map_err(|e| (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()))?;
    }

    Ok(result)
}

// 6. 请求头
// 测试命令:
// curl -X GET 'http://127.0.0.1:3000/api/req6' \
//     -H 'x-auth-token: mock-auth-token-string' \
//     -H 'user-agent: curl' \
async fn handler6(headers: HeaderMap) -> String {
    let mut out = String::new();

    // 获取单个 header
    if let Some(ua) = headers.get("user-agent") {
        out.push_str(&format!("user-agent = {:?}\n", ua));
    }

    // 遍历所有 header, 包括自定义的 header 字段
    for (k, v) in headers.iter() {
        out.push_str(&format!("{}: {:?}\n", k, v));
    }

    out
}

// 7. 原始 Request 实例
// 测试命令:
// curl http://127.0.0.1:3000/api/req7
async fn handler7(req: Request) -> impl IntoResponse {
    let method = req.method().clone();
    let uri = req.uri().clone();
    let version = req.version();
    let headers = req.headers().clone();

    // 注意：Request 被消费后 body 就没了，所以要在销毁前使用
    let body_bytes = axum::body::to_bytes(req.into_body(), usize::MAX)
        .await
        .unwrap_or_default();

    let info = format!(
        "method = {}\nuri = {}\nversion = {:?}\nheaders = {:?}\nbody = {:?}",
        method,
        uri,
        version,
        headers,
        String::from_utf8_lossy(&body_bytes)
    );

    (StatusCode::OK, info)
}
```

### 设置响应信息 Response

响应根据数据组织方式可以分为三类: `字符串` 和 `二进制数据流` 和 `重定向`

- 字符串: text/html/json 等等不同格式的字符串
- 二进制数据流: 图片/视频等静态资源文件下载

::: code-group

```rust [文本字符串]
use axum::{Json, Router, routing};
use serde::Serialize;
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/str1", routing::get(str1_handler))
        .route("/str2", routing::get(str2_handler))
        .route("/json", routing::get(json_handler))
        .route("/html", routing::get(html_handler));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 响应纯文本, 自动设置响应 header
// Content-Type: text/plain; charset=utf-8
async fn str1_handler() -> String {
    String::from("raw string")
}

async fn str2_handler() -> &'static str {
    "raw &str"
}

// 2. 响应 json, 自动设置响应 header
// Content-Type: application/json
#[derive(Serialize)]
struct User {
    id: u32,
    name: String,
}
async fn json_handler() -> Json<User> {
    // 用 Json 包装, axum 自动序列化并设置 header
    // 也可以用 serde 提供的 json! 宏：
    // Json(serde_json::json!({ "id": 1, "name": "alice" }))
    Json(User {
        id: 1,
        name: "alice".to_string(),
    })
}

// 3. 响应 HTML: 自动设置响应头:
// Content-Type: text/html
async fn html_handler() -> axum::response::Html<&'static str> {
    axum::response::Html("<h1>Hello, axum!</h1>")
}
```

```rust [二进制数据流]
use axum::{
    Router,
    body::Body,
    http::StatusCode,
    response::{IntoResponse, Response},
    routing,
};
use tokio::{
    fs::{self, File},
    net::TcpListener,
};

use axum_extra;
use tokio_util;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/down1", routing::get(download_handler1))
        .route("/down2", routing::get(download_handler2))
        .route("/down3", routing::get(download_handler3));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 1. 下载小文件: 一次性将文件内容读取到内存, 然后直接发回客户端
// 注意需要安装依赖, 并开启 attachment 和 file-stream 功能
// cargo add axum-extra@0.12 -F attachment,file-stream
async fn download_handler1() -> axum_extra::response::Attachment<Vec<u8>> {
    // 异步读取文件内容(一次性读取所有)
    let src_filename = "Cargo.toml";
    let content = fs::read(src_filename).await.unwrap_or_default();

    // 构建 Attachment 响应对象
    axum_extra::response::Attachment::new(content)
        // 设置下载时显示的文件名
        .filename(src_filename)
        // 设置下载时显示的 mime-type
        .content_type("application/toml")
}

// 2. 下载大文件: 边读边传, 避免文件过大占用过多内存
// 注意需要安装依赖: cargo add tokio-util@0.7
async fn download_handler2() -> Result<Response, (StatusCode, String)> {
    // 注意这个文件必须存在
    let filename = "demo.mp4";

    // 1.异步打开文件句柄
    let file = File::open(filename)
        .await
        .map_err(|e| (StatusCode::NOT_FOUND, format!("filt not exists: {e}")))?;

    // 2.流式读取文件内容
    let stream = tokio_util::io::ReaderStream::new(file);

    // 3.构建响应对象, 响应头 content-type 为 application/octet-stream
    let file_stream_resp = axum_extra::response::FileStream::new(stream).file_name(filename);

    Ok(file_stream_resp.into_response())
}

// 3. 下载大文件: 边读边传, 与 download_handler2 不同, 不需要 tokio-util
// 是 tokio::fs::File 和 Body::from_stream 构造 body 然后响应, 这种方式的
// 的好处就是可以设置响应内容的 mime-type
async fn download_handler3() -> Result<axum_extra::response::Attachment<Body>, (StatusCode, String)>
{
    // 注意这个文件必须存在
    let filename = "demo.mp4";

    // 1.异步打开文件句柄
    let file = File::open(filename)
        .await
        .map_err(|e| (StatusCode::NOT_FOUND, format!("filt not exists: {e}")))?;

    // 2.流式读取文件内容
    let stream = tokio_util::io::ReaderStream::new(file);

    // 3.构造响应对象的 body 部分
    let body = Body::from_stream(stream);

    // 4.注意与 download_handler2 的不同
    // 4.1)使用 axum_extra::response::Attachment 构造响应而不是 axum_extra::response::FileStream
    // 4.2)响应头: content-type 为: video/mp4
    let attachment = axum_extra::response::Attachment::new(body)
        .filename(filename)
        .content_type("video/mp4");

    Ok(attachment)
}
```

```rust [重定向]
use axum::{Router, response, routing};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let api_router = Router::new()
        .route("/test", routing::get(test_handler))
        .route("/303", routing::get(redirect_handler1))
        .route("/307", routing::get(redirect_handler2))
        .route("/308", routing::get(redirect_handler3));

    let app_router = Router::new().nest("/api", api_router);

    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    let addr = listener.local_addr().unwrap();
    println!("🚀 Server running on: http://{}", addr);

    axum::serve(listener, app_router).await?;
    Ok(())
}

// 0. 被重定向的路由
async fn test_handler() -> String {
    String::from("hello axum")
}

// 1. 默认重定向, 测试命令: curl -i http://127.0.0.1:3000/api/303
async fn redirect_handler1() -> response::Redirect {
    // HTTP/1.1 303 See Other
    response::Redirect::to("/api/test")
}

// 2. 临时重定向, 测试命令: curl -i http://127.0.0.1:3000/api/307
async fn redirect_handler2() -> response::Redirect {
    // HTTP/1.1 307 Temporary Redirect
    response::Redirect::temporary("/api/test")
}

// 3. 永久重定向, 测试命令: curl -i http://127.0.0.1:3000/api/308
async fn redirect_handler3() -> response::Redirect {
    // HTTP/1.1 308 Permanent Redirect
    response::Redirect::permanent("/api/test")
}

// 注意: 根据HTTP/1.0 的规范:
// 临时重定向状态码是: 301
// 永久重定向状态码是: 202
// 而 axum 响应使用的是 HTTP/1.1 的规范
```
